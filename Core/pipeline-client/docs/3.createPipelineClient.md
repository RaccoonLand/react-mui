# 3. createPipelineClient

The factory that binds `PipelineResponse` parsing to a specific axios instance.

- **Package:** `@raccoonland/pipeline-client`
- **File:** `src/client.ts`

## Signature

```ts
export type PipelineClient = {
  fetchPipeline: <T>(path: string, config?: AxiosRequestConfig) => Promise<PipelineResult<T>>
}

export function createPipelineClient(http: AxiosInstance): PipelineClient
```

## Why the axios instance is injected

Auth (Authorization header, token refresh, tenant selection, ETags, tracing) is **infrastructure the host owns**, not
something the pipeline layer should touch. By taking an `AxiosInstance` the package stays framework-neutral: the same
`createPipelineClient` works whether your app uses a single instance, one per API, or a per-tenant factory.

Attach interceptors on the axios instance you pass in, not inside this package.

## Usage

```ts
// api/httpClient.ts
import axios from 'axios'

export const httpClient = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  headers: { Accept: 'application/json' },
})

httpClient.interceptors.request.use((config) => {
  const token = getAccessToken()
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})
```

```ts
// api/pipeline.ts
import { createPipelineClient } from '@raccoonland/pipeline-client'
import { httpClient } from './httpClient'

export const pipelineClient = createPipelineClient(httpClient)
export const fetchPipeline = pipelineClient.fetchPipeline.bind(pipelineClient)
```

Then in a data source:

```ts
export const usersApi = {
  getById: (id: string) =>
    fetchPipeline<UserDto>('/api/users/get-by-id', { method: 'POST', data: { id } }),
}
```

## Error contract

`fetchPipeline` throws — it never returns `{ error, data }`. The thrown value is always one of:

- `PipelineApiError` — the server returned an envelope with non-empty `errors`.
- `NetworkError` — no HTTP response reached the client (DNS, CORS, offline, timeout without response).
- `InvalidPipelineResponseError` — HTTP body was not a `PipelineResponse`.
- Axios `CanceledError` / `AbortError` — request was aborted; leave to the caller / React Query.

The [hooks layer](5.usePipelineQuery-and-Mutation.md) understands these types and routes them to toasts + monitoring.

## Extras — `buildQueryString`

```ts
buildQueryString({ q: 'raccoon', page: 1, active: true, empty: '' })
// => "?q=raccoon&page=1&active=true"
```

Empty strings, `null`, and `undefined` are skipped so URLs stay clean. Values are coerced with `String()` and encoded
via `URLSearchParams`. Use this only for GET query strings — not for POST bodies.
