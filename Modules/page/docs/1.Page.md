# 1. Page

Sticky page header + breadcrumbs + content pane. The building block for every route in the shell.

- **Package:** `@raccoonland/page`
- **File:** `src/Page.tsx`

## Props

```ts
type PageProps = {
  title: string                    // Used for a11y label and as the fallback heading when no breadcrumbs
  breadcrumbs?: BreadcrumbItem[]
  direction?: 'ltr' | 'rtl'        // Defaults to theme.direction
  actions?: ReactNode              // Right-aligned action row (buttons, filters, ...)
  children: ReactNode

  headerSx?: SxProps<Theme>        // Escape hatch for header override
  headerZIndex?: number            // Default 9 — below the shell header, above content
  headerBleed?: boolean            // Default true — negative margins so header spans the padded shell edges
}
```

## Layout

```text
+-----------------------------------------------+
| BreadcrumbNav (or title fallback)   Actions   |  ← sticky header
+-----------------------------------------------+
|                                               |
| children                                      |
|                                               |
+-----------------------------------------------+
```

The header is `position: sticky` at `top: 0` with `backdropFilter: blur(10px)` and `bgcolor: raccoon.background.header`.
`headerBleed` extends the header horizontally over the shell's content padding — the visual effect is that the
header "reaches the shell edges" while the content underneath stays padded. Set `headerBleed={false}` when nesting
a `Page` inside a card or drawer so the header does not visually escape its container.

## `direction`

Defaults to whatever `theme.direction` reports. Only reason to override is if you're rendering a Page inside a
localized frame with a different direction than the outer theme (rare).

## When breadcrumbs are empty

If `breadcrumbs.length === 0`, the header falls back to showing `title` as a small heading. Screen readers get the
`aria-label={title}` on the header element regardless.

## Actions layout

Actions render in a right-aligned `Box` with `flexWrap: 'wrap'` so a wide action set collapses gracefully on
smaller viewports. On `xs` the whole header stacks (breadcrumbs above actions).

## Design notes

- Page has **no i18n dependency**. `title` is a plain string; breadcrumbs carry their own labels.
- The safe-area padding at the bottom is set for touch devices so floating action bars don't overlap the OS
  gesture area (`env(safe-area-inset-bottom, 0px)`).
