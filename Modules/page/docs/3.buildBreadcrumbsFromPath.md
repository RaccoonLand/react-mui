# 3. buildBreadcrumbsFromPath

Build a `BreadcrumbItem[]` from a URL pathname. Optional helper — apps that hand-craft their crumbs (from a route
config, from an entity name, ...) do not need it.

- **Package:** `@raccoonland/page`
- **File:** `src/buildBreadcrumbsFromPath.ts`

## Signature

```ts
export type BreadcrumbPathOptions = {
  pathname: string                            // e.g. '/packages/theme'
  labelForSegment?: (segment, index, href) => string
  root?: BreadcrumbItem                       // Optional first crumb (e.g. Dashboard)
  skipEmpty?: boolean                         // default true
}

export function buildBreadcrumbsFromPath(options: BreadcrumbPathOptions): BreadcrumbItem[]
```

## Behavior

- Split the pathname on `/`, optionally drop empty segments.
- For each segment, accumulate the `href` (`/packages` → `/packages/theme`).
- Ask `labelForSegment(segment, index, href)` for a display label. If omitted, the raw segment string is used.
- The **last** crumb is stripped of its `href` (see `BreadcrumbNav` — the current page shouldn't be a link).
- If `root` is provided, prepend it as-is (its `href` is preserved).

## Example

```tsx
const breadcrumbs = buildBreadcrumbsFromPath({
  pathname: location.pathname,
  root: { label: t('dashboard'), href: '/' },
  labelForSegment: (segment, _index, href) => {
    if (href === '/packages') return t('packages')
    if (href === '/packages/theme') return t('themePackage')
    return segment
  },
})

<Page title={t('themePackage')} breadcrumbs={breadcrumbs} />
```

## Related — icon augmentation

Apps that want icons per crumb typically pair `buildBreadcrumbsFromPath` with a small helper that maps `href` to
an icon. The sample's `Samples/Backoffice/src/layout/breadcrumbIcons.ts` shows the pattern (`withPathBreadcrumbIcons`).

## Design notes

- The helper is intentionally a **pure function** — no hooks, no context. It's usable from workers, tests, and
  route loaders.
- Empty labels do not throw; they render as empty text in the breadcrumb. The `labelForSegment` callback is where
  the app can guard against unknown segments (e.g. show an id shortened).
