# 1. Overview

`@raccoonland/feedback` is the UI-side counterpart to the pipeline-client hooks. It concentrates the three
cross-cutting UI concerns a backoffice needs every day:

1. **Toasts** — transient user-facing notifications (success / error / warning / info + optional action button).
2. **Loading** — a global backdrop or scoped busy signal driven by promises via `withLoading`.
3. **Confirm** — imperative promise-based confirmation dialog with a queue.

- **Package:** `@raccoonland/feedback`
- **Peer deps:** `react`, `react-dom`, `@mui/material`, `@mui/icons-material`, `notistack`

## Layering

```text
Host app
  └── ToastProvider
        └── LoadingProvider
              └── ConfirmProvider
                    └── children  → useToast() / useLoading() / useConfirm()
```

`ToastProvider` must be outermost of the three because `LoadingProvider` and `ConfirmProvider` do not depend on
toasts. Confirm is innermost because its dialog may want to show toasts on outcome.

## What each piece does

| Provider          | Hook              | Primary use                                                                          |
|-------------------|-------------------|--------------------------------------------------------------------------------------|
| `ToastProvider`   | `useToast()`      | `showSuccess/Error/Warning/Info(message, action?)` — thin wrapper over notistack.    |
| `LoadingProvider` | `useLoading()`    | `withLoading(action, { scope, message })` — wraps a promise with a backdrop.         |
| `ConfirmProvider` | `useConfirm()`    | `confirm(options): Promise<boolean>` — imperative confirmation, queued.              |
| `AppDialog`       | —                 | Structured modal (title / content / actions / Enter-to-confirm).                     |
| `AppDrawer`       | —                 | Structured side drawer (title / body / footer).                                      |

## Non-goals

- **Complex notifications center.** Toasts are for transient messages; anything that needs persistence belongs in a
  separate feature.
- **Form validation UX.** Field errors are `@raccoonland/form-kit`'s job.
- **Loading choreography.** Skeletons, per-row spinners, and progress bars are the caller's responsibility.
  `useLoading()` covers the two shapes almost every app needs (global backdrop + counted "any in-flight" signal).
