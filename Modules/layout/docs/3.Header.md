# 3. LayoutHeader

Top bar of the shell. Renders: sidebar/orientation toggles, host-provided start actions, search, theme toggle,
fullscreen, locale toggle, host-provided end actions, notifications, and the user menu.

- **Package:** `@raccoonland/layout`
- **File:** `src/Header.tsx`

## Visibility flags

Every built-in element can be hidden by the host via `header?.show*: false` (all default to `true`, except
`showLocaleToggle` which defaults to `true` only when `onToggleLocale` is provided).

```ts
type LayoutHeaderConfig = {
  showSearch?: boolean
  showThemeToggle?: boolean
  showFullscreen?: boolean
  showNotifications?: boolean
  showOrientationToggle?: boolean
  showLocaleToggle?: boolean
  showUser?: boolean
  startActions?: ReactNode      // between sidebar/orientation toggles and search
  endActions?: ReactNode        // between locale/theme/fullscreen and notifications
}
```

## Slots

Two slots let the host inject its own components without patching the layout:

```tsx
<BackofficeLayout
  header={{
    showSearch: false,
    startActions: <EnvBadge />,
    endActions: (
      <>
        <TenantSwitcher />
        <QuickActions />
      </>
    ),
  }}
  {...rest}
/>
```

`headerActions` (top-level prop) still works but is `@deprecated` — prefer `header.endActions`.

## Search behavior

The built-in search field is a stub — an input with an Enter handler and a mobile dialog fallback. Wire it to your
own search state via the `endActions` slot (or replace it entirely by setting `showSearch: false` and rendering
your own field elsewhere).

## Sidebar toggle logic

The header's leading icon button is context-aware:

- **Mobile** — hamburger / close depending on drawer state.
- **Vertical + `expanded`** — icon collapses to `compact` (one step of the density cycle).
- **Vertical + `compact`** — icon collapses to `collapsed`.
- **Vertical + `collapsed`** — icon expands back to `expanded`.
- **Horizontal** — hidden (no sidebar to toggle).

## Scroll-shadow effect

When the main content scrolls, the header switches to a slightly stronger border + drop shadow. This is driven by
the parent `BackofficeLayoutShell` via `onScroll` on the `<main>` element and passed down as `scrolled` — no
listeners in the header itself.

## User menu

Falls back to a default profile/settings/sign-out trio built from `labels`; hosts override with
`user.menuItems` when they need to add tenant switch, help center, etc. Menu items with `href` render as
`react-router` links; items with `onClick` fire the callback and close the menu.

## Design notes

- Every icon button is `size="small"` and every menu uses `raccoon.background.elevated` — visual consistency comes
  from centralization, not from consumer-provided styles.
- The header does not do i18n. Labels come pre-translated in `LayoutChromeLabels`.
