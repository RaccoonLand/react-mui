# 1. Overview

`@raccoonland/layout` is the backoffice **shell** — top-level chrome that wraps every page: header, sidebar,
content pane, mobile drawer, layout settings (orientation, sidebar density, theme mode), and a fullscreen shortcut.

- **Package:** `@raccoonland/layout`
- **Peer deps:** `react`, `react-dom`, `react-router-dom`, `@mui/material`, `@mui/icons-material`,
  `@raccoonland/theme`, `@raccoonland/feedback`

## Design principle

The package renders **UI only**. Every piece of app-specific data (navigation items, brand name, chrome labels,
user info, locale toggle) is passed in from the host so i18n and business data stay in the host application.

```tsx
<BackofficeLayout
  navigation={navigation}   // LayoutNavItem[] — labels are pre-resolved
  brand={brand}
  direction={direction}
  labels={labels}           // LayoutChromeLabels — 40+ pre-translated strings
  user={user}
  onToggleLocale={toggleLocale}
  header={{ showSearch: true, endActions: <CustomAction /> }}
/>
```

The shell mounts:

```text
<LayoutSettingsProvider>    (orientation + density state, persisted in localStorage)
  <LayoutShellProvider>     (navigation, brand, labels, user — from host)
    <BackofficeLayoutShell> (permanent SidebarVertical / drawer / horizontal nav)
      <LayoutHeader>
      <SidebarHorizontal>?  (only when orientation === 'horizontal')
      <main>
        <Outlet /> or renderMain() or children
```
