# 1. Overview

`@raccoonland/data-table` renders a **server-driven** list as **MUI X Data Grid (Community)**
on wide viewports and as cards below a breakpoint. The host owns fetch, filters, confirm
dialogs, and i18n labels.

- **Package:** `@raccoonland/data-table`
- **Peer deps:** `react`, `react-dom`, `@mui/material`, `@mui/icons-material`,
  `@mui/x-data-grid` (Community), `@raccoonland/theme`
- **Not a peer:** pipeline-client, feedback, form-kit, layout, `@mui/x-data-grid-pro`

## Owns / does not own

| Owns | Does not own (v1) |
| --- | --- |
| Data Grid + card chrome | Fetch / API |
| Column definition + cell render | Search / filter UI (host) |
| Row actions (inline + overflow menu) | Delete confirm / toasts |
| Checkbox selection (table **and** cards), sort, context menu | Export, column pin, bulk toolbar |
| Controlled pagination UI (custom footer) | Data Grid built-in footer pagination |
| Responsive table ↔ cards switch (+ optional multi-column cards) | Client-side pagination of a full dataset |

## Engine

Desktop table mode uses **`@mui/x-data-grid` Community**. Built-in column menu, client sort,
and the grid footer are disabled so pagination stays on the package’s numbered footer.

Later (Sarv): swap the host peer to `@mui/x-data-grid-pro` and bump this package when Pro-only
APIs are required.

## Quick start

```tsx
import { DataTable } from '@raccoonland/data-table'
import EditIcon from '@mui/icons-material/Edit'
import DeleteIcon from '@mui/icons-material/Delete'

<DataTable
  rows={data.items}
  getRowId={(r) => r.id}
  columns={[
    { id: 'name', header: t('name'), render: (r) => r.fullName, cardPrimary: true },
    { id: 'status', header: t('status'), render: (r) => <StatusChip v={r.status} /> },
  ]}
  actions={[
    { key: 'edit', label: t('edit'), icon: EditIcon, onClick: (r) => navigate(`…/${r.id}`) },
    { key: 'delete', label: t('delete'), icon: DeleteIcon, color: 'error',
      onClick: async (r) => { if (await confirm(…)) delete(r.id) } },
  ]}
  page={page}
  pageSize={pageSize}
  totalCount={data.totalCount}
  onPageChange={setPage}
  onPageSizeChange={(s) => { setPageSize(s); setPage(0) }}
  labels={{
    rowsPerPage: t('rowsPerPage'),
    displayedRows: (from, to, count) => t('displayedRows', { from, to, count }),
    labelActions: t('actions'),
    moreActions: t('moreActions'),
  }}
  loading={isFetching}
/>
```
