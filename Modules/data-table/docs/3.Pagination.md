# 3. Pagination

Pagination is **controlled and server-driven only**.

The host passes the **current page’s** `rows` plus:

| Prop | Meaning |
| --- | --- |
| `page` | 0-based page index |
| `pageSize` | Rows requested from the API |
| `totalCount` | Total matching rows (server) |
| `onPageChange` | `(page: number) => void` |
| `onPageSizeChange` | `(pageSize: number) => void` |
| `pageSizeOptions` | Default `[10, 25, 50]` |

## Controls

The footer includes:

- Rows-per-page select
- Displayed range text (`from`–`to` of `count`)
- Numbered page buttons with ellipsis (e.g. `1 2 3 … 9 10`)
- **First** / **previous** / **next** / **last** controls

The Data Grid Community footer is **hidden**; pagination is owned by this package footer only.

`page` stays **0-based** in the public API; the UI maps to 1-based page numbers for display.

Typical host pattern when page size changes:

```ts
onPageSizeChange={(size) => {
  setPageSize(size)
  setPage(0)
}}
```

## Labels (i18n from host)

```ts
type DataTableLabels = {
  rowsPerPage: string
  displayedRows: (from: number, to: number, count: number) => string
  labelActions?: string
  moreActions?: string
  firstPage?: string
  lastPage?: string
  nextPage?: string
  previousPage?: string
  /** Cards: aria-label for the select-all-on-page checkbox. */
  selectAll?: string
  /** Cards: aria-label for a per-row select checkbox (receives the row id). */
  selectRow?: (rowId: string | number) => string
}
```

## Loading

When `loading` is true:

- A thin `LinearProgress` shows at the top of the paper
- Content opacity is reduced and pointer events are blocked
- Pagination controls are disabled

The package never fetches data.

## Empty state

When `rows` is empty (table overlay + cards):

| Prop | Role |
| --- | --- |
| `emptyIcon` | Optional MUI icon component (default `InboxOutlined`) |
| `emptyMessage` | Optional text / node under the icon (host i18n) |
| `emptyContent` | Full custom ReactNode — overrides the two above |

**Fallback:** if neither `emptyContent` nor `emptyMessage` is set, only the icon is shown (default or `emptyIcon`).

```tsx
<DataTable
  emptyIcon={SearchOffOutlinedIcon}
  emptyMessage={t('noPeople')}
  {/* … */}
/>
```

```tsx
// Icon-only fallback (package default icon)
<DataTable rows={[]} {/* … */} />
```
