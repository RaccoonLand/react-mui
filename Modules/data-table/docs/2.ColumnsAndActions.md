# 2. Columns and actions

## Columns

```ts
type DataTableColumn<T> = {
  id: string
  header: ReactNode
  renderHeader?: () => ReactNode   // optional override of header cell content
  headerSx?: SxProps<Theme>        // optional per-column header cell styles
  align?: 'start' | 'center' | 'end'
  width?: number | string
  sortable?: boolean            // per-column; default true when DataTable sortable
  hideOnCard?: boolean
  cardPrimary?: boolean
  cardLabel?: ReactNode
  render?: (row: T, index: number) => ReactNode
}
```

- Without `render`, the cell shows `row[id]` when `id` is a key of `T` and the value is a
  primitive (`string` | `number` | `boolean`).
- `header` / `cardLabel` are host-owned nodes — typically `t('…')`.
- Use `renderHeader` when the header needs interactive or composed UI (sort affordance,
  icon + label, etc.). Use `headerSx` for one-off header cell styling.
- The desktop engine is **MUI X Data Grid Community**; header uses a **solid** primary tint
  (opaque `color-mix`) plus the same scrolled-header shadow as `@raccoonland/layout`
  (`0 6px 20px` with text alpha). Header `zIndex` is local (`2`) so it stays **below** the
  Page breadcrumb (`9`). Pass `maxHeight` on `DataTable` to make the body scroll while the
  header stays sticky.

## Selection (optional, table + cards)

```tsx
<DataTable
  checkboxSelection
  selectedRowIds={selectedIds}
  onSelectionChange={setSelectedIds}
  // disableMultipleRowSelection  // single-select
  …
/>
```

Default off. Works in both the desktop table (`@mui/x-data-grid` checkbox
column with select-all in the header) and in cards (per-card checkbox plus a
select-all-on-page checkbox above the list). When `disableMultipleRowSelection`
is on, cards hide the select-all control.

Provide localized aria labels via `labels.selectAll` and
`labels.selectRow(rowId)`.

The select-all path uses the Data Grid `include` selection model
(`disableRowSelectionExcludeModel` is set on our behalf) so
`onSelectionChange` always receives a real id list, not an inverse model.

## Sorting (optional, table mode)

```tsx
<DataTable
  sortable
  sortingMode="server"   // default — host reorders / re-fetches
  sortModel={sortModel}
  onSortModelChange={(model) => { setSortModel(model); setPage(0) }}
  columns={[
    { id: 'name', header: t('name'), sortable: true },
    { id: 'status', header: t('status'), sortable: false },
  ]}
  …
/>
```

Use `sortingMode="client"` only to sort the rows currently passed in (current page).

## Context menu (optional)

Right-click menu with three switches:

```tsx
contextMenu={{
  enabled: true,   // کلی
  row: true,       // ردیف — same items as the actions column
  table: true,     // جدول — tableItems below a separator
  tableItems: [
    { key: 'refresh', label: t('refresh'), onClick: () => refetch() },
    { key: 'export', label: t('export'), onClick: () => exportCsv() },
  ],
}}
```

- Row right-click: row actions → separator → table items (when both sections are on and non-empty)
- Empty chrome / header right-click: table items only
- Works in table and card views

### Custom header example

```tsx
{
  id: 'status',
  header: t('status'),
  renderHeader: () => (
    <Stack direction="row" spacing={0.5} alignItems="center">
      <ChipIcon fontSize="small" />
      <span>{t('status')}</span>
    </Stack>
  ),
  headerSx: { minWidth: 120 },
  render: (r) => <StatusChip v={r.status} />,
}
```

## Actions

Actions are a **dedicated column** (table) / footer (cards), not a normal column.

```ts
type DataTableAction<T> = {
  key: string
  label: string              // tooltip + a11y; host i18n
  icon?: SvgIconComponent
  color?: 'inherit' | 'primary' | 'error' | 'warning'
  disabled?: (row: T) => boolean
  hidden?: (row: T) => boolean
  onClick: (row: T) => void
}
```

### Overflow menu

Visible actions (after `hidden`) are split:

1. First `maxInlineActions` (default **2**) → `IconButton` + `Tooltip`
2. Remaining → `MoreVert` menu (`labels.moreActions` for a11y)

Pass `maxInlineActions={0}` to put every action in the menu, or a higher number to show more inline.

Omit `actions` or pass `actions={[]}` to hide the actions column entirely.

Destructive work (confirm + mutate) stays in the host `onClick`.
