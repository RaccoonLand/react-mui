# 4. Responsive cards

## View mode

| `viewMode` | Behavior |
| --- | --- |
| `'auto'` (default) | Cards when viewport is below `cardBreakpoint` |
| `'table'` | Always table |
| `'cards'` | Always cards |

`cardBreakpoint` defaults to `'md'` and is passed to `theme.breakpoints.down(...)`.

Helper for tests:

```ts
import { isDataTableCardView } from '@raccoonland/data-table'

isDataTableCardView('auto', true)  // → true
isDataTableCardView('table', true) // → false
```

## Default card layout

1. **Title** — column with `cardPrimary: true`, else the first column that is not `hideOnCard`
2. **Fields** — remaining non-`hideOnCard` columns as label/value rows (`cardLabel` or `header`)
3. **Actions** — same inline + overflow behavior as the table

## Customizing a card row

Pass `renderCard` to compose or replace the body. The context always includes the package-built pieces:

```ts
type DataTableCardRenderContext<T> = {
  row: T
  index: number
  title: ReactNode
  fields: { id: string; label: ReactNode; value: ReactNode }[]
  actionNodes: ReactNode
  /** True when this row is currently in `selectedRowIds`. */
  selected?: boolean
  /**
   * Checkbox control for `checkboxSelection`. Place it wherever fits your
   * custom card layout (e.g. left of the avatar).
   */
  selectionControl?: ReactNode
}
```

Example — custom header, default fields, package actions, package selection checkbox:

```tsx
<DataTable
  checkboxSelection
  renderCard={({ row, title, fields, actionNodes, selectionControl }) => (
    <Box sx={{ display: 'flex', alignItems: 'flex-start' }}>
      {selectionControl ? <Box sx={{ pl: 1, pt: 1.25 }}>{selectionControl}</Box> : null}
      <Box sx={{ flex: 1, minWidth: 0 }}>
        <CardContent>
          <Stack direction="row" spacing={1} alignItems="center">
            <Avatar>{row.initials}</Avatar>
            <Typography variant="subtitle1">{title}</Typography>
          </Stack>
          {/* map fields… */}
        </CardContent>
        <CardActions sx={{ justifyContent: 'flex-end' }}>{actionNodes}</CardActions>
      </Box>
    </Box>
  )}
  {/* … */}
/>
```

The outer `Card` chrome (border / surface tokens, selected/context tint,
`aria-selected`) stays in the package; `renderCard` fills its interior.
